## Code
Use [main.py](https://github.com/Samuel-CHLam/rnn_ergodicity/blob/main/main.py) to simulate the data. This will output either the full (smoothed) sequence of memories or their summary statistics (first and second moments.) See further [hidden_layer_ergodicity_3_torch.ipynb](https://github.com/Samuel-CHLam/rnn_ergodicity/blob/main/hidden_layer_ergodicity_3_torch.ipynb) and [hidden_layer_ergodicity_final_time_avg.ipynb](https://github.com/Samuel-CHLam/rnn_ergodicity/blob/main/hidden_layer_ergodicity_final_time_avg.ipynb) for the codes for generating plots.
